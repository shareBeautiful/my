一、简介

定义

　　jQuery创始人是美国John Resig，是优秀的Javascript框架； 　　jQuery是一个轻量级、快速简洁的javaScript库。源码戳这

jQuery对象

　　jQuery产生的对象时jQuery独有的，只能自己调用

书写规则

　　支持链式操作； 　　在变量前加"$“符号（var $variable = jQuery 对象）； 　　注：此规定并不是强制要求。
