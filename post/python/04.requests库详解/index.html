requests库详解

什么是 requests

Requests 使用Python语言编写的，基于urllib,采用 Apache2 Licensed 开源协议的HTTP库。它比urllib更加方便，可以节约我们大量的工作，完全满足HTTP测试需求。 ————Python实现的简单易用的HTTP库。

requests用法

requests请求方式

  1. get()
  2. post()
  3. put()
  4. delete()
  5. head()
  6. options()
1
2

import requests
request.get(url,headers,params,cookies,timeout)

1. GET请求

1
2

request.get(url,headers,params,cookies,files,timeout,verify=False,allow_redirects=False,proxies)
request.get(url,headers,data,cookies,files,timeout,verify=False,proxies)

' url：请求地址
params: dict 请求菜参数
headers: dict 请求头(User-Agent,Cokkies等)
cookies: dict 请求的cookies
timeout: int 请求的时间，超过报错
files: dict 上传文件的字典
verify： bool 是否验证证书合法
cert: toupl 证书
allow_redirects: 是否重定向 proxies dict 设置代理ip地址

2. POST请求

1

requests.post(url,header,data,cookies,timeout)

requests响应response

  1. response.status_code 获取状态码
  2. response.text 获取响应的字符串
  3. response.content 获取响应的二进制数据流
  4. response.headers 获取响应头
  5. response.cookies 获取响应cookie
  6. response.json() 解析json数据类似于json.loads()
  7. response.url 获取url地址
  8. response.history 获取响应访问的历史记录

import requests
from requests import ConnectTimeout,HTTPError,ConnectionError,RequestException
try:
    r = requests.get('http://httpbin.org/get', timeout=0.1)
    print(r.status_code)
except ConnectTimeout:
    print('Time out')
except HTTPError:
    print('Http error!')
except ConnectitonError:
    print('Connectiton error!')
except RequestException as e:
    print(e)
    print('request error!')
