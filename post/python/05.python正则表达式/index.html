正则表达式

1. re.match

re.match尝试从字符串的起始位置匹配一个模式，如果不是起始位置匹配成功的话，match()就返回none 可以用group(1)获取匹配的值 re.match(pattern,string,flags=0)

如果使用分组()可以用group(1)获取第一个匹配()的值,使用groups()获取值组成的元祖,group(0)或group()返回所有匹配的字符串

1
2
3
4
5
6

import re
content = 'Hello 123 4567 World_This is a Regex Demo'
result = re.match('^Hello.*Demo$', content)
print(result)
print(result.group())
print(result.span())

2. re.search

re.search 扫描整个字符串并返回第一个成功匹配的

1
2
3

import re
content = 'Extra strings Hello 1234567 World_This is a RegExp Demo Extra stings'
result = re.search('Hello.*?(\d+).*?Demo', content)

3. re.findall

搜索字符串，以列表形式返回全部能匹配的字串

import re
html = '''<div>
<ul>
    <li><a href="/1.html">aaa</a></li>
    <li><a href="/2.html">bbb</a></li>
    <li>
        <a href="/3.html">ccc</a>
    </li>
</ul>
</div>'''
result = re.findall('<li.*?href="(.*?)".*?>(.*?)</a>', html, re.S)
print(result) # [('/1.html', 'aaa'), ('/2.html', 'bbb'), ('/3.html', 'ccc')]

4. re.sub()

替换字符串中每一个匹配的子串后返回替换后的字符串 re.sub(pattern,newstring,string)

1
2
3
4

content = 'Extra strings Hello 1234567 World_This is a RegExp Demo Extra stings'
result = re.sub('(\d+)',r'\1aaaa',content) # r'\1'表示把元字符中第一个元素
print(result)
# Extra strings Hello 1234567aaaa World_This is a RegExp Demo Extra stings

还可以传递一个lambda函数

1
2
3
4
5

s = 'a-AA-b-BB-c-CC'
d = {'a': '1', 'b': '2', 'c': '3'}
pat = '(a|b|c)'
res = re.sub(pat, lambda x: str(d[x.group()]), s)
print(res) # '1-AA-2-BB-3-CC'

5. re.compile()

将正则字符串编译成正则表达式对象，以便于在后面的匹配中复用

1
2
3
4

content = 'Extra strings Hello 1234567 World_This is a RegExp Demo Extra stings'
pattern = re.compile('Hello.*Demo', re.S)
res = re.match(pattern, content) # 或写法
res = pattern.patch(content)

捕获分组

命名捕获

命令组的语法是 Python 专用扩展之一： (?P<name>...)。名字很明显是组的名字。除了该组有个名字之外，命名组也同捕获组是相同的。MatchObject 的方法处理捕获组时接受的要么是表示组号的整数，要么是包含组名的字符串。命名组也可以是数字，(?P=word)获取反向引用，所以你可以通过两种方式来得到一个组的信息：

1
2
3
4

p = re.compile(r'(?P<word>\b\w+\b)')
m = p.search( '(((( Lots of punctuation )))' )
m.group('word') # 'Lots'
m.group(1) # 'Lots'

贪婪匹配和非贪婪

在限定符中，除了{n}确切表示重复几次，其余的都是一个有下限的范围。 在默认的模式（贪婪）下，会尽可能多的匹配内容。比如用ab去匹配字符串“abbb”，结果是“abbb”。 而通过在限定符后面加问号?可以进行非贪婪匹配，会尽可能少地匹配。用ab?去匹配“abbb”，结果会是“a”。 不带问号的限定符也称匹配优先量词，带问号的限定符也称忽略匹配优先量词。

匹配模式

  • re.I使匹配对大小写不敏感
  • re.L做本地化识别（locale-aware）匹配
  • re.M多行匹配，影响 ^ 和 $
  • re.S使 . 匹配包括换行在内的所有字符
  • re.U根据Unicode字符集解析字符。这个标志影响 \w, \W, \b, \B.
  • re.X该标志通过给予你更灵活的格式以便你将正则表达式写得更易于理解。

re.S可以使.*匹配包含换行符的任意字符

1
2
3
4

content = '''Hello 123 4567 World_This
is a Regex Demo'''
result = re.match('^He.*?(\d+).*Demo$', content, re.S)
print(result)
