标准选择器

find_all(name, attrs, recursive, text, **kwargs) 可以根据标签名、属性、内容查找文档

1

print(soup.find_all('p'))

find_all(attrs={‘id’=link1'})
find_all(class_=‘sister’) find_all(text=‘Foo’)

  • find(name, attrs, recursive, text, **kwargs)
  • find_parents(), find_parent()
  • find_next_siblings(), find_next_siblibg()
  • find_previous_siblings(), find_previous_sibling()
  • find_all_next(), find_next()
  • find_all_previous(), find_previous()

CSS选择器

通过select()直接传入css选择器,返回一个列表 soup.select('.box')
soup.select('#box')
soup.select(‘a’)
soup.select('.parent li')

总结

  1. 推荐使用 lxml解析库，需要时使用html.parse
  2. 标签选择器选择功能弱但是速度快
  3. 建议使用find()、find_all()查询匹配单个结果或多个结果
  4. 如果对css选择器熟悉建议使用select()
