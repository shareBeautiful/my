一.变量

1.变量命名及规范

  • 一个变量包括两方面：变量名和变量值。
  • 变量名开头必须 字母 或 下划线。
  • python命名区分大小写。
  • 这种变量本身类型不固定的语言称之为动态语言，与之对应的是静态语言。静态语言在定义变量时必须指定变量类型，如果赋值的时候类型不匹配，就会报错。例如Java是静态语言

列表可以通过引用其元素，改变对象自身(in-place change)。这种对象类型，称为可变数据对象(mutable object)，词典也是这样的数据类型。
而像之前的数字和字符串，不能改变对象本身，只能改变引用的指向，称为不可变数据对象(immutable object)。
我们之前学的元组(tuple)，尽管可以调用引用元素，但不可以赋值，因此不能改变对象自身，所以也算是immutable object.


1> 不可变对象
    a = 'abc';
    b = a.replace('a','A')
    print(a)  // 'abc'
    要始终牢记的是，a是变量，而'abc'才是字符串对象！有些时候，我们经常说，对象a的内容是'abc'，但其实是指，
    a本身是一个变量，它指向的对象的内容才是'abc'：当我们调用a.replace('a', 'A')时，
    实际上调用方法replace是作用在字符串对象'abc'上的，而这个方法虽然名字叫replace
    ，但却没有改变字符串'abc'的内容。相反，replace方法创建了一个新字符串'Abc'并返回，如果我们用变量b指向该新字符串，
    就容易理解了，变量a仍指向原有的字符串'abc'，但变量b却指向新字符串'Abc'了：

    所以，对于不变对象来说，调用对象自身的任意方法，也不会改变该对象自身的内容。相反，
    这些方法会创建新的对象并返回，这样，就保证了不可变对象本身永远是不可变的。
2> 可变对象 list，dict
	改变对象自身。这种对象类型，称为可变数据对象

4. 类属性和类方法

  • 直接在类中定义的属性为类属性

  • 在类中定义的方法都是 实例对象 的方法，如果先用@classmethod 然后定义就成了类方法，类方法传递一个cls参数，cls表示类对象本身。

  • 类属性和方法对实例对象是共享的。

  • 类对象，可以在外部直接调用类属性(除私有)，也可以外部直接调用类方法(除私有)

  • 但是类对象，不允许访问 实例属性，并且也不允许调用实例方法

  • 如果是一个实例对象，它可以获取实例属性和类属性的值，但是只能修改实例属性

  • 不能修改类属性，会覆盖类属性

  • 它还可以调用 实例方法 和 类方法

  • 在类内部，类方法中可以访问类的属性和方法(包括私有的)，但是不能访问实例的属性和方法(无论共私) 实例方法中可以访问实例的属性和方法也可以访问类的属性和方法 如果实例属性和类属性有相同的，则实例属性覆盖类属性

  • 在类外部，类对象只能访问类属性和方法(不能访问私有的)，也不能访问实例的属性和方法 实例对象可以访问实例的属性和方法(不能访问私有的)也可以访问类的属性和方法(不能访问私有的)
    如果实例属性和类属性有相同的，则实例属性覆盖类属性

class Student(object):

    def score(self):
        return self._score
    @score.setter
    def score(self, value):
        if not isinstance(value, int):
            raise ValueError('score must be an integer!')
